# Contributing

Report bugs with synthetic steps, expected behavior and actual behavior. For capture failures, describe the selected devices and warnings in your own words. Do not attach real audio, transcripts, screenshots or unreviewed metadata. See [Privacy](docs/privacy.md).

Keep changes focused. Core logic belongs in `FeedbackCore`; platform integrations belong in the app target. Run the checks documented in the README and the relevant [manual checks](docs/manual-check.md). Explain what was verified and what still needs hardware testing.
